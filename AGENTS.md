# Project Instructions & Style Guide

## Core Design Principles
- **Aesthetic:** Swiss/Modern meets Editorial Elegance.
- **Typography:** Inter (Sans) for UI, Playfair Display (Serif) for headings.
- **Layout:** High contrast, meticulous attention to detail, polished transitions.

## Default Color Palette (Saved as Standard)
- **Primary:** `#154212` (Deep Green)
- **Secondary:** `#c5a059` (Gold/Brass)
- **Surface:** `#f9faf2` (Off-white/Beige)
- **Error:** `#ba1a1a` (Deep Red)

## Development Rules
- Always maintain the balance between organic aesthetics and professional stability.
- Use `framer-motion` (motion/react) for all animations.
- Ensure all admin features are secured via Firebase and handle errors gracefully.
- Support multi-language content (PT, EN, ES) using the established content key pattern (e.g., `key`, `key_en`, `key_es`).
